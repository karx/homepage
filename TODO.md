# Urban Prana — Launch Wishlist

> Working list of everything needed to take the site from current state to production-ready.
> Priority: P0 = blocker, P1 = launch-critical, P2 = post-launch.

---

## P0 — Blockers (must have before going live)

### Brand Assets
- [ ] **Logo** — supply `assets/images/urban-prana-logo.png` (400×120 px, transparent) and `.svg` version
- [ ] **Favicon** — 512×512 SVG/PNG source to generate all sizes (16, 32, 96, 180, 192 px). Current `favicon.ico` is an Akriya placeholder.
- [ ] **OG / social preview image** — `assets/images/urban-prana-og.jpg` (1200×630) for Twitter/Facebook cards

### Domain & Hosting
- [ ] Confirm `urbanprana.life` DNS is pointing to hosting (Netlify / GitHub Pages / custom server)
- [ ] Enable HTTPS; update `url:` in `_config.yml` if domain changes
- [ ] Update Google Analytics tracking ID (`UA-125563076-1` is an Akriya ID) or migrate to GA4

### Contact Form
- [ ] Wire up the contact form in `/contact/` to a backend (Netlify Forms, Formspree, or similar) — currently static HTML with no submission handler
- [ ] Add CSRF / spam protection (honeypot field or reCaptcha)

## P2 — Post-Launch Improvements

### Features
- [ ] **Booking integration** — embed Calendly or a custom scheduler on `/contact/`
- [ ] **WhatsApp CTA** — floating button or inline link to WhatsApp Business number
- [ ] **Newsletter opt-in** — lightweight email capture (Mailchimp / ConvertKit embed) on journal and contact pages
- [ ] **Search** — lunr.js is already configured; add a `/search/` page and test it works
- [ ] **Related posts** — confirm `related: true` in post defaults is surfacing relevant journal posts
- [ ] **Structured data** — add `LocalBusiness` JSON-LD schema to homepage for local SEO (Noida, Delhi NCR)

### Design Polish
- [ ] **Lab/Retreats section** — `_includes/landing/labs.html` uses placeholder content; populate with real retreat or workshop offerings
- [ ] **Dark mode** — audit all `--up-*` tokens for dark mode equivalents; add `prefers-color-scheme: dark` media query
- [ ] **Print stylesheet** — basic print styles for case studies and philosophy pages
- [ ] **Micro-animations** — entrance animations (`@keyframes fade-up`) on section headers as they scroll into view (currently only the hero mandala animates)

### Content Pipeline
- [ ] Publish 2 more journal posts to round out the `/journal/` to 6 posts (currently 4)
- [ ] Set up content calendar: minimum 1 post/month cadence
- [ ] Add author bio block to journal posts once author identity is finalised
- [ ] Create `/workshops/` page if in-person or online sessions are launched

### Technical
- [ ] **Image optimisation** — run all photos through Squoosh/ImageOptim; target <200 KB per image
- [ ] **Service Worker / PWA** — `manifest.json` is present; wire up a basic service worker for offline caching
- [ ] **CI/CD** — update `.github/workflows/jekyll.yml` to use a newer `jekyll/builder` image and cache gems
- [ ] **Accessibility audit** — run Axe or Lighthouse; fix any contrast or ARIA violations introduced by the custom skin
- [ ] **Lighthouse score** — target 90+ on Performance, Accessibility, Best Practices, SEO before launch
- [ ] Consider migrating to Jekyll 4.x + Sass 3.x to silence deprecation warnings from current build
